This directory contains the Neutrino implementation imported from upstream
`main` at `4a82cd22f474c31ac2fecfa174d381a19bb3f469`. The official OSDI artifact
evaluation is pinned separately at `43182f3082f5617d8bc85cd8902af4f6fbaeeb24`;
its notebooks and environment helper are preserved under `evaluation/`.

[`../original/README.md`](../original/README.md) for source ZIP checksums and
[`REPRODUCING.md`](REPRODUCING.md) for static and dynamic reproduction steps.
