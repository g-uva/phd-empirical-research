# Neutrino

Neutrino is a programmable GPU-kernel profiler described in the OSDI 2025
paper “Neutrino: Fine-grained GPU Kernel Profiling via Programmable Probing.”

- Paper: [`paper/2025-neutrino-osdi.pdf`](paper/2025-neutrino-osdi.pdf)

- Reproduction procedure: [`artifact/REPRODUCING.md`](artifact/REPRODUCING.md)
- Metadata: [`metadata/paper.json`](metadata/paper.json) and
  [`metadata/artifact.json`](metadata/artifact.json)
- Experiment index: [`artifact/experiments/index.json`](artifact/experiments/index.json)
- Preserved upstream snapshots: [`original/README.md`](original/README.md)

The source and official artifact-evaluation materials are present, but no
Neutrino experiment has yet been executed in this workspace.
